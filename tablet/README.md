# 番匣平板适配版

基于已存档的手机版 0.1.13，保留同一套片库、账号登录、播放、离线下载、观看进度和备份功能。本目录是可独立构建的 Android 项目，目标设备为华为 MatePad Pro 2021。

## 安装与兼容

这是平板适配 APK，不是鸿蒙原生 HAP。能运行 Android APK 的系统可直接安装；具体鸿蒙版本尚未确认，其他系统的兼容运行方式需要在实际平板上验证。不能仅凭“最新系统”判断能否安装。

包名及签名沿用手机版。若平板已装番匣手机版，可覆盖安装并保留该设备的数据；升级前也可在设置中导出片库备份。平板版单独使用 `downloads/tablet/latest.json` 检查更新，不会被手机版更新替换。

手机版备份可以导入平板，保留番剧、设置和各集进度。备份不包含登录凭据和视频文件；平板需单独登录、下载。各设备的数据不自动云同步。

## 大屏交互

- 按当前窗口宽度切换布局，兼顾横屏、竖屏和分屏窗口。
- 宽度达到 600dp 时使用侧边导航；达到 840dp 时播放与选集、离线番剧与下载详情使用双栏。
- 首页封面随宽度调整列数，最近观看使用更大的海报。
- 窗口变化保留当前播放位置、清晰度、播放状态和列表选择；全屏保留同一播放器。
- 触摸手势、长按倍速、左侧亮度、右侧音量、锁屏、选集、离线优先与本地续播沿用手机版。

## 构建与验证

在仓库根目录执行 `gradle -p tablet :app:testDebugUnitTest :app:assembleDebug :app:lintDebug`，或使用 `Build tablet APK` 工作流。工作流核对版本、APK 签名和测试报告，再发布 APK、安装 ZIP、校验值及更新清单。

自动测试不能代替 MatePad 真机验证；实际 HDR 显示、后台下载和系统分屏行为仍取决于设备及系统。
