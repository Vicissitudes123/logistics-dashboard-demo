# 番匣 Windows 版 0.1.13.1

面向 Windows 11 x64，功能以手机版 0.1.13 为基线：片库搜索、置顶与移除、选集与续播、离线优先、清晰度记忆、批量下载与删除、下载进度、备份恢复和主题设置。电脑与手机各自保存数据，不会自动同步。

## 打开与更新

1. 下载发布页的 `anime-shelf-desktop-0.1.13.1-windows-x64.zip`，完整解压。
2. 打开 `AnimeShelf` 文件夹，运行 `AnimeShelf.exe`。请保留旁边的 `_internal` 文件夹；无需另外安装 Python、Java 或播放器。
3. 在「B站登录」中使用官方扫码登录，或在「添加番剧」中导入本地视频。扫码二维码在本机生成。

更新前退出通知区中的旧程序，将新包解压到新文件夹后运行即可。测试版没有商业代码签名；发布页附带 SHA-256 校验文件，可用于核对下载是否完整。

## 数据与备份

默认数据目录为 `%LOCALAPPDATA%\AnimeShelf\AnimeShelf`，通常是 `C:\Users\你的用户名\AppData\Local\AnimeShelf\AnimeShelf`。片库与进度在 `library.json`，下载文件和任务在 `offline`，封面缓存在 `covers`，桌面设置在 `desktop-settings.json`。登录状态在 `session.dat`，使用 Windows 当前用户的 DPAPI 加密。设置页的「打开离线文件夹」可以直接找到视频。

删除或替换解压出来的程序文件夹不会清除这些数据。开发测试可用环境变量 `ANIME_SHELF_DATA_DIR` 指定独立数据目录。

「设置 → 导出片库备份」可保存番剧、逐集观看进度和可迁移的设置。桌面版可以读取番匣手机版的 v1–v4 JSON 片库备份；恢复时合并片库，并保留本机更新的观看记录。备份**不包含视频、下载任务、登录 Cookie 或本地文件授权**：换设备后需要重新登录，重新下载或导入视频。自动备份仅在程序运行时执行，保留最近 7 份。

## 操作与实际限制

- 播放区单击显示控制栏，双击播放/暂停，长按临时加速；左右拖动调整进度，左侧上下拖动调整视频亮度，右侧上下拖动调整音量。亮度调整作用于视频画面，不会改变显示器背光。
- 播放区获得焦点后，空格播放/暂停，左右方向键前后跳转 5 秒，上下方向键调音量，`F` 切换全屏，`Esc` 返回。窗口较窄时，倍速、选集和画面功能收进「更多」。
- HDR 需要视频源、显卡、驱动、显示器和 Windows HDR 设置共同支持。构建检查会验证解码、双音视频轨、跳转及实际播放器窗口，不代表已验证你的电脑能正确输出 HDR。
- 网络请求使用系统或环境中的静态 HTTP/HTTPS 代理设置；不保证支持 PAC 自动脚本、WPAD 或需要交互认证的代理。若某条链路连接失败，可先核对 Windows 的手动代理与网络出口。
- 默认仅 Wi-Fi/有线网络下载。VPN、虚拟网卡或无法识别的网络可能让任务等待，可在设置中自行调整。关闭到通知区可继续下载；完全退出后停止传输，下次启动保留任务。
- 清晰度与可用视频由账号权限和平台返回结果决定。在线播放地址可能过期；完整离线文件不依赖该临时地址。桌面版没有额外提高源视频码率，也不会把普通视频变成 HDR。

## 构建与验证

Windows 环境需要 Python 3.12 x64、JDK 17 和 7-Zip，在本目录执行 `./build_windows.ps1`。脚本校验固定原生组件下载、运行 132 项 Java 解析断言及桌面测试，再验证打包后的媒体组件、Windows 播放器窗口和 EXE 界面，最后生成 ZIP、SHA-256 与发布清单。

原生组件的版本和摘要见 `build-lock.json`，来源与第三方许可见 `licenses/NOTICE.txt`。构建报告保存在 `reports`，发布包在 `dist/release`。
