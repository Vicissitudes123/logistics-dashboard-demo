# 番匣 · 安卓离线追番工具

原生安卓测试版，Android 8.0（API 26）及以上。中文界面，视频、账号会话和观看记录保存在设备本地，不需要部署服务器。

**已生成可安装的安卓测试 APK。** 已通过 60 项解析回归断言、Android 编译、Lint 和 APK 签名验证；尚未进行实体手机或用户账号下的番剧下载测试。具体状态见 `BUILD_STATUS.md`。

## 使用

1. 安装发布目录中的 APK。
2. 打开「番匣」，点「B站登录」，在 B 站官方网页内完成登录，再点「完成登录，返回番匣」。无需向其他人提供密码或 Cookie。
3. 点「＋ 添加」→「粘贴 B站番剧 / 视频链接」，输入分享文本、b23.tv 短链、ep/ss 番剧链接或 BV 视频链接。
4. 选集后，工具读取当前会话实际可用的清晰度和编码。选一个版本，再选「在线播放」或「下载到本机」。
5. 「离线下载」页显示任务状态。只有画面与声音都保存完成，才显示「离线播放」。完成后可以断网观看。
6. 在番剧库点「继续观看」，回到该部番最后观看的一集和保存的位置。每集进度独立保存，切集或退出时也会保存。

播放器提供上一集/下一集、0.5～3 倍速、横屏全屏、适应/铺满、50%～300%画面缩放。也可以多选本地视频，命名为一部番剧后播放；本地文件不能被移走或删除。

## 这版的范围

- 接入 B 站现有网页接口，支持番剧季/集和普通 BV 视频分 P。接口可能变化、需要登录或受风控影响。
- 清晰度以接口真实返回的媒体流为准，可能包含不同编码；手机不支持某种编码时，请选择 AVC/H.264 版本。
- 下载地址失效时，需要重新解析同一集同一格式，再继续任务。网络暂停保留已经下载的数据。
- 离线文件由应用管理；本版没有导出合并 MP4 功能。不同清晰度可分别保存。
- 截图中的「版权受限」不能直接证明是否有 DRM。该番剧能否下载仍需用具体链接和账号验证。本版没有 DRM 离线授权接入，也不将试看当成完整剧集；接口没有可用媒体时会显示失败原因。
- 不支持旧式多段 FLV 合并；遇到此类源会明确提示，不保存不完整的一集。
- 后台下载使用安卓前台通知。系统可能因省电策略或 Android 15 的后台时间限制暂停任务，回到应用后可继续。
- 文件保存在应用私有存储中，卸载应用或清除应用数据会移除下载内容和记录；不提供云端同步。

## 构建

需要 JDK 17+、Android SDK Platform 35、Build Tools 35.0.0。Gradle Wrapper 为 8.9，Android Gradle Plugin 为 8.7.3，Media3 为 1.5.1。

```sh
./gradlew :app:assembleDebug :app:lintDebug
```

设置 `ANDROID_HOME` 或在本机 `local.properties` 中配置 `sdk.dir`。不要提交本地 SDK 路径、会话文件或签名密钥。输出为 `app/build/outputs/apk/debug/app-debug.apk`。这是开发签名的测试包；正式分发时应配置自己的发布签名，并持续保存密钥以便以后更新。

源码包没有二进制 wrapper JAR，需先安装 Gradle 8.9。附有 GitHub Actions 构建流程：向 `anime-shelf-apk` 分支提交或手动触发后构建并输出 APK artifact。CI 在工作区生成并缓存测试签名密钥；后续构建应继续使用同一缓存密钥，以便覆盖安装更新。

`tests/ParserSelfTest.java` 是离线解析回归测试，使用合成的接口响应检查真实清晰度、音视频配对、权限错误和 JSON 序列化，不访问用户账号。编译与静态检查不替代安卓手机上的播放/后台下载测试。

## 代码结构

- `BiliClient`：链接、番剧元数据、可用媒体和错误解析。
- `MediaRepository` / `AnimeDownloadService`：Media3 双轨持久缓存、下载队列和仅本地播放。
- `MainActivity`：片库、选集、下载、文件导入和播放器。
- `Store`：本地片库与每集观看记录。
- `LoginActivity`：官方登录网页，账号 Cookie 仅用于 B 站 API 请求。

本工程使用 AndroidX Media3 等开源组件，第三方组件遵循其各自许可证。
