# 番匣 · 安卓离线追番工具

原生安卓测试版，Android 8.0（API 26）及以上。中文界面，视频、账号会话和观看记录保存在设备本地，不需要部署服务器。

[下载 0.1.6 安装 ZIP](https://raw.githubusercontent.com/Vicissitudes123/logistics-dashboard-demo/c1c2570d311b7cc8550dd6210dc413851322e9c1/downloads/anime-shelf-0.1.6-install.zip)（解压后安装 APK），或[直接下载 APK](https://raw.githubusercontent.com/Vicissitudes123/logistics-dashboard-demo/c1c2570d311b7cc8550dd6210dc413851322e9c1/downloads/anime-shelf-0.1.6.apk)。已核对与旧版签名一致，可覆盖安装保留片库、离线文件与观看记录，不要先卸载旧版。

**当前交付为 0.1.6。** 新增首页搜索、移除与恢复、置顶和设置，默认主题为蓝色。105 项解析断言和 127 项 JUnit/Robolectric 测试通过；详情见 `BUILD_STATUS.md`。手机交互仍需安装后确认。

## 使用

1. 安装发布目录中的 APK。
2. 打开「番匣」，点「B站登录」，在 B 站官方网页内完成登录，再点「检查登录」。看到核验结果后点「返回番匣」。网页显示头像不单独作为已登录依据，无需向其他人提供密码或 Cookie。
3. 点「＋ 添加」→「粘贴 B站番剧 / 视频链接」，输入分享文本、b23.tv 短链、ep/ss 番剧链接或 BV 视频链接。
4. 选集后，工具读取当前会话实际可用的清晰度和编码。选一个版本，再选「在线播放」或「下载到本机」。
5. 「离线下载」先按番剧分组，进入后按集数升序显示，各清晰度分别保留。只有画面与声音都保存完成，才显示「离线播放」。完成后可以断网观看。
6. 在番剧库点「继续观看」，回到该部番最后观看的一集和保存的位置。每集进度独立保存，切集或退出时也会保存。
7. 顶部「首页」或底部「首页 · 番剧库」返回首页，保存观看进度并收起播放器。进入下载页同样收起播放器；全屏时点击画面显示控件，可退出全屏，系统返回键先退出全屏，再返回首页。

播放器支持单击显示/隐藏控制栏、双击播放/暂停、右下角切换全屏。水平滑动预览进度，松手后跳转；左半屏上下滑动调播放窗口亮度，右半屏上下滑动调媒体音量。长按画面默认临时 2 倍速（设置可调整），松手恢复长按前的速度。选集、速度和画面显示方式在视频内的控制栏中选择。

也可以多选本地视频，命名为一部番剧后播放；本地文件不能被移走或删除。

## 0.1.6 首页整理与设置

- 首页最上方搜索框支持部分片名、英文大小写和全半角统一；多个关键词用空格分开时同时匹配，如「高木」「JOJO 钻石」。这是片名关键词匹配，不包含拼音和错别字纠正。
- 搜索框下面依次显示最近观看的一部、置顶番剧、其他番剧；最近观看同时置顶时只显示一次。未播放的新导入番剧不会替代最近观看。
- 长按首页番剧卡片或点击「管理」，可置顶、取消置顶或从首页移除。移除需确认，保留已下载视频和观看记录；「设置 → 已移除番剧」可恢复，重新导入也会恢复显示。
- 底部新增设置。主题默认蓝色，可选紫、青、绿、橙、粉，立即更新按钮、进度条及后续弹窗强调色。
- 可设常用倍速、长按加速 1.5/2/2.5/3 倍和控制栏隐藏时间 3.5/5/8 秒或不自动隐藏。长按松手恢复原速，原速更高时不降速。
- 设置显示离线任务数量和保存字节数，提供恢复已移除番剧与重置偏好入口。重置仅影响外观和播放设置，不删除片库、置顶、隐藏状态、下载、观看记录或登录。

## 0.1.5 亮度、长按与多选

- 左侧上下滑调当前播放窗口亮度（5%～100%），右侧调音量，左右滑动预览进度并在松手后跳转。亮度不修改系统设置，也不申请修改系统设置权限；暂停到后台或返回首页时恢复原窗口亮度。
- 播放中的视频画面长按约半秒后临时 2 倍速（常用速度已高于 2 倍时不降速）。松手恢复原速，不修改保存的常用倍速；滑动、多指、取消、失去焦点、切集和退后台都会取消加速。按钮与进度条不触发画面长按；暂停画面不会因长按而自动播放。
- 播放、返回、首页、全屏等控件只保留白色图标/文字，去掉常驻底色与边框，保留按下反馈及原有点击区域。
- 番剧列表长按一集进入原页面多选，自动勾选该集；再点击其他集切换勾选，可全选、取消或下载所选集。导入的本地视频无需下载。
- 离线页长按视频条目进入多选删除；在离线目录长按番剧可选中整部，也可跨番剧选择。多选期间点击只勾选，返回键先退出多选；刷新下载进度保留选择。删除仍需确认，并保留观看记录。

手势参考 [B站播放器操作教程](https://www.bilibili.com/video/BV1zw411n7Dc/)，松手恢复此前速度按用户要求实现，不保证所有 B站版本或播放模式操作完全一致。

## 0.1.4 批量下载、HDR 与显示

- 进入番剧后点击「批量下载」，勾选集数或全选，再选择统一清晰度和编码。选项参考首个选中集；其他集逐集核对，缺少该档位会跳过并报告，不静默降档。已有同档位跳过，失败任务重新解析重试。
- 加入队列期间保持前台；停止加入或切到后台会取消剩余解析，已加入的下载继续。下载页支持批量勾选删除和删除整部，确认框显示选中版本数及大小，保留番剧库和观看记录。
- 离线列表按番剧标识分组、按数字集数排列，标题相同的不同番剧不会合并，同一集的不同版本不会丢失。
- 播放图标改为 32dp 画布、至少 48dp 点击区域，修复高密度屏幕上图标被缩得过小的问题。
- 视频输出改用 SurfaceView。Android 官方说明 TextureView 在 Android 13 及以上会将 HDR 转成 SDR；SurfaceView 适合 HDR，但仍需设备、解码器和视频流共同支持。
- 「画面 → 视频信息 / HDR」显示实际解码格式的分辨率、色彩传递、已知位深、码率和屏幕 HDR 能力。平台的“HDR”标签、屏幕支持能力和截图均不能单独证明实际 HDR 输出；应用不会据标签宣称 HDR 已启用。
- 下载保存平台提供的音视频数据，不额外转码，不会还原平台原有的压缩损失。码率显示区分平台标称值与视频格式信息，并非实时测量。
- 未指定清晰度标识的 DASH 视频不再借用顶层标签。缺失档位会明确提示；一般 I/O 错误按连接中断、提前结束、TLS、本地文件等原因提供安全诊断，仍需具体错误判断，不把所有失败归因为没有该分辨率。

参考：[Android HDR 播放](https://developer.android.com/media/grow/hdr-playback)、[Media3 Surface 类型](https://developer.android.com/media/media3/ui/surface)。真机 HDR 与缩放效果需安装后验证。

## 0.1.3 播放器交互

控制栏覆盖在视频内，播放时约 3.5 秒自动隐藏；单击显隐、双击播放/暂停。倍速支持 0.25～3 倍，画面支持适应/铺满及 50%～300% 缩放。全屏时隐藏应用页头与底部导航，退出后恢复原界面。水平滑动预览跳转位置并在松手时提交，右侧纵向滑动调媒体音量，左侧纵向滑动按用户偏好改为调倍速；按钮、进度条与画面手势分别处理，避免互相抢触摸事件。

交互参考 B站公开的[横屏播放器手势教程](https://www.bilibili.com/video/BV1zw411n7Dc/)及[单双击切换教程](https://www.bilibili.com/video/BV14p4y1u7sH)。不同 B站版本/播放模式可有差异；本应用按本次明确需求实现，不声称复刻 B站全部功能。

## 0.1.2 修复范围

- API 和媒体请求分别配置浏览器标识：网页媒体流使用桌面浏览器 User-Agent，API 与登录行为保持原有配置。
- 媒体请求最终采用当前标识，旧下载记录或旧 DataSpec 中的手机 UA 不能把修复覆盖回去；不改签名链接、字节范围或缓存键。
- 返回首页、进入下载列表时保存进度并释放播放器，避免黑屏播放器占住页面；播放错误框新增返回首页操作。
- 导航回归覆盖首页、下载页、播放与全屏返回；构建成功后校验原有签名并提供可用浏览器下载的 APK。

用户已在手机确认 0.1.2 恢复播放。兼容性依据见[同类安卓客户端的 CDN UA 修复](https://github.com/yearzen1/bilibili-pure-apk/commit/61908e12db99acbcb2df135a100cecc4ac2e6147)。公开媒体样本在同一出口下完成 UA 对照，手机 UA 返回 403，桌面 UA 返回 206 及有效 MP4 文件头；不代表所有剧集和网络环境均已验证。

## 已保留的 0.1.1 修复

- 保留接口给出的主地址和备用地址。媒体连接失败时，可在限定候选列表内尝试备用地址，保留原请求的字节范围与缓存键。

- 完成登录时校验当前 API 会话；网页唤起 B 站 App 被拦截，不再直接提示为登录失败。

自动化测试不能替代用户账号与网络环境下的复测。HTTP 403 表示服务器拒绝请求，具体原因仍需结合实际请求判断。

## 这版的范围

- 接入 B 站现有网页接口，支持番剧季/集和普通 BV 视频分 P。接口可能变化、需要登录或受风控影响。
- 清晰度以接口真实返回的媒体流为准，可能包含不同编码；手机不支持某种编码时，请选择 AVC/H.264 版本。
- 下载地址失效时，需要重新解析同一集同一格式，再继续任务。网络暂停保留已经下载的数据。
- 离线文件由应用管理；本版没有导出合并 MP4 功能。不同清晰度可分别保存。
- 截图中的「版权受限」不能直接证明是否有 DRM。该番剧能否下载仍需用具体链接和账号验证。本版没有 DRM 离线授权接入，也不将试看当成完整剧集；接口没有可用媒体时会显示失败原因。
- 不支持旧式多段 FLV 合并；遇到此类源会明确提示，不保存不完整的一集。
- 后台下载使用安卓前台通知。系统可能因省电策略或 Android 15 的后台时间限制暂停任务，回到应用后可继续。
- 文件保存在应用私有存储中，卸载应用或清除应用数据会移除下载内容和记录；不提供云端同步。

## 存储与离线有效性

下载存放在安卓应用内部文件目录 `files/offline-media`，通常为 `/data/user/0/com.animeshelf.app/files/offline-media/`（多用户设备路径可能不同）。这是 Media3 管理的音视频分轨缓存，不是系统下载目录里的单个 MP4；请从应用的「离线下载」页播放和删除。观看记录和下载索引也保存在本机。

当前实现没有按日期或会员到期时间删除已完成下载，也没有离线时联网核验会员：选择「离线播放」时没有网络上游，只读本地已完整保存的音画轨。对当前支持的非 DRM 内容，账号会员到期本身不会令这些本地字节失效。下载不完整、文件损坏或被删除时则不能离线播放；新下载、重新解析和在线访问仍取决于服务端权限。没有接入 DRM 离线许可，不能据此推断 DRM 内容可永久观看。

卸载、清除应用数据、主动删除任务或丢失手机会丢失下载和记录；覆盖更新会保留这些数据。媒体网页接口、登录方式、风控或视频编码变化时，工具可能需要更新，不必跟随 B 站 App 的每一次版本更新。

## 构建

需要 JDK 17+、Android SDK Platform 35、Build Tools 35.0.0。Gradle Wrapper 为 8.9，Android Gradle Plugin 为 8.7.3，Media3 为 1.5.1。

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

设置 `ANDROID_HOME` 或在本机 `local.properties` 中配置 `sdk.dir`。不要提交本地 SDK 路径、会话文件或签名密钥。输出为 `app/build/outputs/apk/debug/app-debug.apk`。这是开发签名的测试包；正式分发时应配置自己的发布签名，并持续保存密钥以便以后更新。

源码包没有二进制 wrapper JAR，需先安装 Gradle 8.9。附有 GitHub Actions 构建流程：向 `anime-shelf-apk` 分支提交或手动触发后构建并输出 APK artifact。CI 在工作区生成并缓存测试签名密钥；后续构建应继续使用同一缓存密钥 `anime-shelf-debug-signing-v2`，以便覆盖安装更新。artifact 附带 `apk-signature.txt` 证书报告；更新前可核对新旧 APK 的签名证书 SHA-256。缓存若被清理，需要恢复原签名密钥；不能仅凭相同缓存键保证签名永远不变。

`tests/ParserSelfTest.java` 使用合成接口响应检查清晰度、音视频配对、权限、备用地址、登录验证及 JSON 序列化，不访问用户账号。`app/src/test` 的 JUnit/Robolectric 测试覆盖请求头、候选切换、Range、缓存键和导航。可选的 `tests/probe_media_request.py` 仅对公开流做最多 1024 字节的请求对照，不使用用户账号，也不打印签名链接；外部 API 拒绝时只记录无法得出结论，不把它当成实测通过。artifact 包含测试、Lint、包信息、签名证书及该对照日志。编译与自动化测试不替代安卓手机上的播放和后台下载验证。

## 代码结构

- `BiliClient`：链接、番剧元数据、可用媒体和错误解析。
- `MediaRepository` / `AnimeDownloadService`：Media3 双轨持久缓存、下载队列和仅本地播放。
- `MainActivity`：片库、选集、下载、文件导入和播放器。
- `Store`：本地片库与每集观看记录。
- `LoginActivity`：官方登录网页，账号 Cookie 仅用于 B 站 API 请求。

本工程使用 AndroidX Media3 等开源组件，第三方组件遵循其各自许可证。
